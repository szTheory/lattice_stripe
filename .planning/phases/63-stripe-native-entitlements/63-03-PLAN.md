<objective>
Complete `LatticeStripe.Entitlements.Feature` — the entitlement feature *definition* resource — with
its full Stripe verb surface and the two moduledoc sections that teach what no function signature can.

Purpose: ENT-04's create/retrieve/update/list is not a partial surface; it is the *complete* one.
Stripe ships no DELETE for features, so this module is finished when those four verbs plus streaming
land. The genuinely valuable work here is documentation: the `active` field versus the `archived`
filter is a two-words-one-concept split that makes a naive reconciler report archived features as
deletions, and `lookup_key`'s immutability after create is what makes it safe to key host
configuration on. Neither fact is visible from any function name.

Output: the finished `Feature` module and `feature_test.exs` with the L2 present/absent surface locks.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `Feature.create/3` / `update/4` | Caller-supplied catalog data crosses into a write request against the connected Stripe account. |
