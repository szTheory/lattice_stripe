<objective>
Lock the explanation, then run the phase's five gates.

Purpose: the structural locks from plans 63-01 and 63-03 lock the *code* — which verbs exist and
which never will. They cannot lock the *reason*. If the gate-helper admonition or the archiving
warning is deleted in a future cleanup, the code stays correct and the next reader re-derives the
fail-open design from scratch. Docs-truth is this project's answer: `File.read!` plus `=~` over both
guides and `lib/` sources, running as its own required CI lane.

Three prose locks, no more. A grep for a generic sentence about following `has_more` would be noise —
the ten-assertion stream suite is the real structural proof, and a redundant prose lock erodes trust
in the mechanism.

Output: one new docs-truth test cloned from the tax-guide template, an extension to the existing
`guides/scope.md` lock, and a recorded green run of all five phase gates.
</objective>
