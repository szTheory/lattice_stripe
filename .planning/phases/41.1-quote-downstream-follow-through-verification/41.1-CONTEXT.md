# Phase 41.1: Quote Downstream Follow-Through Verification - Context

**Gathered:** 2026-05-25
**Status:** Ready for planning
**Source:** Phase 41 scope split after repo-local `stripe-mock` probe

<domain>
## Phase Boundary

Own the exact downstream follow-through proof that Phase 41 could not truthfully complete inside its `stripe-mock`-bounded closure scope.

This is a narrow follow-up verification phase, not a reopening of Quote API design. It exists because Phase 41 research proved that the current repaired local `stripe-mock` returns `invoice=nil`, `subscription=nil`, and `subscription_schedule=nil` after `Quote.accept/3`, which makes the old roadmap requirement to retrieve one downstream resource under `stripe-mock` non-executable as written.

</domain>

<decisions>
## Implementation Decisions

### Why this phase exists

- **D-41.1-01:** Phase 41 now closes only the Quote evidence that current `stripe-mock` can truthfully provide.
- **D-41.1-02:** Phase 41.1 owns the displaced requirement to prove exactly one downstream retrieve after `Quote.accept/3`.
- **D-41.1-03:** This phase must not back-port unsupported claims into Phase 41’s verifier just to make the roadmap look cleaner.

### Proof shape

- **D-41.1-04:** The target follow-through depth remains: `Quote.create/3 -> Quote.finalize/4 -> Quote.accept/3 -> inspect returned downstream reference -> retrieve exactly one linked downstream Stripe resource -> stop`.
- **D-41.1-05:** Prefer downstream targets in this order:
  - `invoice`
  - otherwise `subscription`
  - otherwise `subscription_schedule`
- **D-41.1-06:** The downstream retrieve must assert typed top-level decode only. Do not broaden into payment, activation, webhook, or orchestration semantics.

### Scope limits

- **D-41.1-07:** Do not reopen Quote parser/API work already covered by Phase 36 and Phase 41 unless a fresh probe reveals a substantive shipped behavior defect.
- **D-41.1-08:** Keep the phase focused on proving one downstream retrieve in an environment that actually exposes such a reference.
- **D-41.1-09:** If the chosen environment still cannot expose a downstream reference, record that fact and escalate again instead of inventing proof.

</decisions>
