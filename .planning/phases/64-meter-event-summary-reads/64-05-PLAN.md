<objective>
Add the phase's only novel guard: a pre-network raise that catches a misaligned window timestamp, prints
the arithmetic to fix it, and refuses to choose between flooring and ceiling.

Purpose: Stripe's alignment rule is machine-readable and exact, so a guard has zero false positives — but
Stripe's error code for violating it is undocumented, so this library cannot improve the resulting 400
after the fact. It can only prevent it. Meanwhile the natural input source is always wrong: a
subscription's period boundaries derive from its billing cycle anchor and land on an arbitrary second,
violating even the universal minute rule. This guard makes LatticeStripe the only Stripe SDK in any
language that catches this before the wire.

Output: `Billing.Guards.check_summary_window!/2`, its two call sites, and the alignment matrix tests.
</objective>
