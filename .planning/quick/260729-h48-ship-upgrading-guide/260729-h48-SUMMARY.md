# Summary — Ship the orphaned upgrading guide

## Outcome

`guides/upgrading-1-1-to-1-7.md` is on `main` and rendered on HexDocs under its own "Upgrading"
group. `origin/phase-62-upgrading-guide` can now be deleted; its content is shipped.

## How it was found

During git cleanup, the local `main` checkout was 13 commits ahead of `origin/main`. The
expectation was that these were pre-squash duplicates of merged PRs. Checking content rather than
trusting that assumption showed one commit carried a 340-line guide that existed nowhere on
`origin/main` — real unshipped work, one `git reset --hard` away from being lost.

rewrite it to the current line:

- `VersionProse.@install_surfaces` is an explicit 7-file allowlist; this guide is absent from it.
- `docs_truth_test.exs` `@stale_release_status_claims` is asserted against `README.md` only.

Same hazard class as the historical CHANGELOG pins — a correct historical version that automation
must leave alone.
