### Integration warning — non-blocking, dormant

`entitlements.active_entitlement_summary` is correctly registered for snapshot-webhook deserialization, but ObjectTypes also gates `Webhook.fetch_related_object/3`. If Stripe ever sends this no-id, non-retrievable summary as a v2 related object, the generic helper will attempt a GET that cannot succeed. Current Stripe delivery uses the v1 snapshot shape; the behavior is documented and characterization-tested. A future change should model “registered but not individually retrievable” explicitly. Affected requirements: OBJ-01, ENT-05.

This warning does not invalidate either requirement today; it accounts for the integration checker’s 12/13 score and is tracked as debt.
